业务服务层
以 Spring Cloud 微服务为载体，各服务独立部署，服务间通过 OpenFeign 同步调用；对外经网关暴露 REST 接口；承载领域规则、事务边界与安全鉴权，是平台业务逻辑的中枢。
server-user
用户资料、RBAC、游戏/区服/段位等基础数据维护；对外提供登录、注册与菜单路由接口。
server-order
订单状态机、发布与接单、取消审核、异常单处理、客服介入与平台仲裁。
server-account
账户余额、冻结/解冻、充值提现、资金流水及与支付宝等支付渠道对接。
jmz-file
文件上传、格式校验、与阿里云 OSS 对接，业务库仅保存对象引用 URL。
server-ai
封装通义千问等大模型，提供智能定价建议、订单文案优化与代练人员接单推荐。
server-websocket
WebSocket 长连接管理、即时通讯消息收发与订单状态推送；结合 Redis 实现跨实例路由。

图意说明：本图为游戏代练平台系统功能包图，展示后端微服务模块划分及包间依赖关系。最外层「游戏代练平台」为顶层系统包；接入层（jmz-gateway）统一接收前端请求并路由分发；公共基础包（jmz-common）以六子包形式提供工具类、Redis、MyBatis-Plus、Feign、Security 与配置等横切能力，被所有业务服务依赖复用；业务服务层包含用户（server-user）、订单（server-order）、账户（server-account）、文件（jmz-file）、AI（server-ai）与 WebSocket（server-websocket）六个独立部署单元；安全策略包（jmz-security）统一提供 JWT 与接口级鉴权；基础设施层（Nacos、Seata、MySQL、Redis、OSS）与第三方集成（支付宝、微信支付、通义千问）处于系统边界，为平台运行所依赖的外部组件。各包与业务服务层之间以虚线双向箭头（⟷）表示双向协作与数据回写关系。
