# 摘要

随着电子竞技产业的蓬勃发展，游戏代练服务市场日益壮大。然而，传统平台存在信息不对称、匹配效率低、服务质量难保障等突出问题。

本文设计了一套面向游戏代练的智能化平台系统，采用前后端分离与微服务架构，前端基于Vue3，后端以Spring Boot为基础依托Spring Cloud进行服务拆分，划分为网关、用户、订单、AI推荐及WebSocket消息通讯等模块，采用Nacos、MySQL、Redis与阿里云OSS保障系统稳定运行。系统围绕订单发布、接取、履约、验收及仲裁等环节构建完整业务闭环，通过WebSocket实现实时双向通讯，并引入阿里云百炼平台的大语言模型服务，提供发单价格建议、订单文案优化与智能接单推荐三项智能化功能。

本系统的研究为"AI + 垂直服务平台"的工程化落地提供了可复用的设计思路，对于推动游戏服务行业的数字化转型具有一定的理论与实践价值。

**关键词**：游戏代练平台；微服务架构；大语言模型；WebSocket

## Abstract

With the rapid development of the esports industry, the game boosting service market has grown significantly. However, traditional platforms face issues such as information asymmetry, low matching efficiency, and difficulty in ensuring service quality.

This paper designs an intelligent game boosting platform using a front-end and back-end separated architecture with microservices. The front-end is built with Vue3, while the back-end uses Spring Boot and Spring Cloud with gateway, user, order, AI recommendation, and WebSocket services. Infrastructure includes Nacos, MySQL, Redis, and Alibaba Cloud OSS. The system implements a complete business loop around order publishing, acceptance, performance, verification, and arbitration, with real-time bidirectional communication via WebSocket. It also integrates Alibaba Cloud Bailian's large language model to provide intelligent functions including order pricing suggestions, description optimization, and order recommendations.

This research provides reusable design references for "AI + vertical service platforms" and holds theoretical and practical value for promoting digital transformation in the game service industry.

**Keywords**: Game Boosting Platform; Microservice Architecture; Large Language Model; WebSocket
