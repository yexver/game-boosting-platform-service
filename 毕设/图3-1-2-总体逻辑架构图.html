架构说明

（1）核心应用流程（自左向右）。 表现层采用 Vue 3、Element Plus、Pinia 构建前端，经 HTTPS 与后端建立连接。 Spring Cloud 微服务体系为一大框，其内依次为： 接入层使用 Spring Cloud Gateway，负责请求路由、跨域处理与安全鉴权； 业务服务层基于 Spring Boot、Spring MVC、Spring Security 实现领域逻辑，微服务之间通过 OpenFeign 进行同步调用； 业务服务层与框内的基础设施层（Nacos、Seata）、第三方集成（支付宝、微信支付）之间以双向箭头表示注册发现、配置拉取、分布式事务协调及支付回调等双向协作； 数据层由 MySQL 承担业务主数据与事务持久化，Redis 提供缓存与热点数据支撑，OSS 提供非结构化文件与对象存储。

（2）组件关系说明。 Nacos 承担服务注册与统一配置；Seata 协调跨服务分布式事务；第三方支付渠道负责充值、提现等资金通道（具体以业务实现为准）。上述组件与业务服务同处于 Spring Cloud 微服务体系边界内，便于在论文图中表达「业务中枢 + 外围协作」的一体化结构。
