# 致谢

时光荏苒，岁月如梭，转眼间四年的大学生活即将画上句点。在论文完成之际，我怀着无比感激的心情，向在这段求学路上给予我帮助与支持的所有师长、亲友致以最诚挚的谢意。

首先，我要向我的指导老师致以最深切的感谢。从课题的选择到系统的设计，从技术难点的攻克到论文的撰写，老师始终给予我悉心的指导与耐心的帮助。每当我在研究与开发过程中遇到困惑与瓶颈时，老师总能以其深厚的学术造诣和丰富的工程经验为我指点迷津，帮助我理清思路、找到突破口。老师严谨求实的治学态度、孜孜不倦的工作作风以及对学生无微不至的关怀，令我深受感动，也将成为我今后学习与工作中的榜样。

其次，我要感谢计算机学院的各位授课老师。是你们在课堂内外的辛勤付出，为我奠定了扎实的专业理论基础，使我能够系统地掌握软件开发的核心技术与方法。感谢学院为我们提供的良好学习环境与科研条件，让我在大学四年里能够安心学习、专心研究。

感谢实验室的同学们在项目开发过程中给予我的帮助与支持。我们一起讨论技术方案、一起攻克开发难题、一起分享学习心得，这段并肩作战的经历将成为我大学生活中最珍贵的回忆之一。特别感谢项目组的小伙伴们，大家在系统设计与实现过程中各展所长、密切配合，共同完成了整个平台项目的开发工作。

感谢阿里云、Nacos、Spring Boot、Vue.js 等开源项目与云服务平台的开发者与维护者，是你们的无私奉献为我的毕设提供了坚实的技术支撑。同时感谢 Vue 3 官方文档、Spring Boot 参考指南、Nacos 官方文档等资源的作者与贡献者，这些详实的技术文档为我的系统开发提供了重要的参考依据。

我还要特别感谢我的家人。感谢父母多年来的养育之恩与默默付出，是你们在背后一直支持我、鼓励我，给予我坚持下去的勇气与力量。每当我遇到困难与挫折时，你们的关心与鼓励总能让我重新振作、继续前行。你们对我的期望与信任，是我不断进步的最大动力。

最后，感谢百忙之中抽出宝贵时间审阅本论文的各位专家与评委老师，感谢你们对本文提出的宝贵意见与建议，这些都将对我今后的学习与研究产生深远的影响。

值此毕业之际，再次向所有关心、帮助和支持过我的老师、同学、朋友和家人表示最衷心的感谢！愿你们身体健康、工作顺利、生活幸福！
